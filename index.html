Dailynews Social Publisher

Dailynews Social Publisher is a desktop publishing tool operated by Dailynews, a Korean digital news media organization.

The service is used to publish vertical short-form news videos created by Dailynews to TikTok accounts that have explicitly authorized the application.

Terms of Service Privacy Policy Dailynews

How the integration works

Dailynews creates its own short-form news video content. After a TikTok account authorizes the application through TikTok Login Kit, the application may transfer an approved video file to TikTok using the Content Posting API.

Before publishing, the integration queries creator information, displays available privacy options supplied by TikTok, and requires an explicit publishing confirmation. Publication is made only to an authorized TikTok account.

TikTok API usage

The integration uses TikTok account authorization, basic creator information, and the Content Posting API for authorized video publishing. Video files are transferred from the Dailynews desktop publishing system using FILE_UPLOAD.
