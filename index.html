Dailynews TikTok Publisher

Dailynews TikTok Publisher is a publishing integration operated by Dailynews, a Korean digital news media organization.

The service is used to publish vertical short-form news videos created by Dailynews to a TikTok account that has explicitly authorized the application.

Terms of Service Privacy Policy Dailynews

How the integration works

Dailynews creates its own short-form news video content. After a TikTok account authorizes the application through TikTok Login Kit, the application may transfer an approved video file to TikTok using the Content Posting API.

Before publishing, the integration queries creator information and uses privacy options supplied by TikTok. Publication is made only to an authorized TikTok account.

TikTok API usage

The integration uses TikTok account authorization and the Content Posting API for authorized video publishing. Video files are transferred directly from the Dailynews publishing system using FILE_UPLOAD.
